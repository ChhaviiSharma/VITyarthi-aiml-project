# TITLE OF THE PROJECT - House Price Predictor

## OVERVIEW OF THE PROJECT -
It is a system which tells about the price of a house based on the space , number of bedrooms and timespan of the house .
It automatically predict the price of the house with the help of simple calculation and a formula .

## FEATURES -
1. It allows to predict the price of the house with the help of libraries and formulas and on the basis of area of the house , number of bedrooms a house contains and timespan of the house .
2. Allows user to input the details about the type of house and customise the area , bedrooms and timespan .
3. Gives separate values of the variable such as 'w1' , 'w2' , 'w3' , 'b' which are used in the formula .
4. Calculates the rate of the house in seconds once the input is given .
5. Each and every step is clearly mentioned making the code easy to understand .
6. Comments are added for the better understanding .

## TECHONOLOGIES AND TOOLS USED -
1. 'pandas' and 'LinearRegression' are  the libraries which are imported .
2. Dictionary is used to store the details about the house such as area , number of bedrooms , and the timespan of the house .
3. Multiple values are stored in the List .
4. Data is converted into tabular form using 'pd.DataFrame()' .
5. Training function is used .
6. Input function is used to enter values and customise the house according to the user .
7. Rate predictor 'model.predict()' is used to predict the price of house .

## STEPS TO INSTALL AND RUN THE PROJECT -
1. Install python and VScode so that you can run the python code .
2. Firstly run the code and then enter the details of the house .
3. Then the rate predictor will calculate and predict the price of the house .
4. Finally the rate will be calculated and will be visible on the screen .
